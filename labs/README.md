# Labs

Local docker targets for testing framework modules against real services.
**Documentation: [wiki/Labs.md](../wiki/Labs.md)** — shipped labs,
credentials, adding your own, the Windows story, and the gotcha
collection.

Quick version: `lab up web` in the console, `lab down web` when done,
`lab clean` to nuke everything. Everything binds to 127.0.0.1 only.
